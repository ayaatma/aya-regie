- Answer an architecture question with one recommendation and its reason, not a menu of options.
- The developer pushes back when a diagnosis looks shaky, and is usually right to. See
  [[feedback-verify-root-cause-before-fixing]].
- They write in French; product-facing text is French, code and notes are English (CLAUDE.md).

**Why:** stated at the start of the project and confirmed across sessions.

**How to apply:** every answer and proposal on this project.
